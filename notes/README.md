# Notes: which are current, which are working logs

These notes were written while the archive was being built, between 27 and 28 June 2026. Some are reference documents that still describe the archive; many are dated working logs kept for the record. Nothing has been deleted. Where a later run overtook an earlier statement, the older note carries a dated "Superseded:" line at its top.
